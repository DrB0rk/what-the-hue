# What the Hue

Send a Philips Hue Touchlink reset to one bulb by serial number when its normal power-cycle reset does not work. The app reads the current Zigbee network ID from ZHA, pauses ZHA while it uses the coordinator, then restores ZHA.

Use the **Open Web UI** button to enter the six-character serial printed on the bulb. Keep it powered on within 10 cm of the coordinator.
